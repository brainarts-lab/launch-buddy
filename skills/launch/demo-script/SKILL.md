---
name: demo-script
description: Turn a README or notes into a 60-second demo video script with five to seven scenes, each with screen and voice.
---

1. Open with the result on screen in the first five seconds. Explanations come later.
2. Write five to seven scenes. For each scene give:
   - Time: start and end in seconds
   - Screen: what the viewer sees, as an instruction the builder can follow while recording
   - Voice: what is said, at most twenty words
3. Show one complete path from start to result. Leave settings, edge cases and
   installation details out unless they are the point.
4. Use only features the material describes. Mark anything you assumed with "Assumption:".
5. End with how to try it, in one sentence.
6. Total length 60 seconds or less. State the total.

After the script, list what to prepare before recording, in at most three points.
